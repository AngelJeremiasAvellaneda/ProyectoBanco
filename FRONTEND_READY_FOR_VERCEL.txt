🚀 PASOS PARA DEPLOY EN VERCEL:
────────────────────────────────────────────────────────────────────────────────

1️⃣  PUSH A GITHUB
    git add .
    git commit -m "chore: prepare frontend for vercel deployment"
    git push origin main

2️⃣  CREAR PROYECTO EN VERCEL
    • Ir a https://vercel.com/dashboard
    • Click "Add New Project"
    • Seleccionar repositorio: banco
    • Root Directory: frontend/  ⚠️ IMPORTANTE!
    • Click "Deploy"

3️⃣  CONFIGURAR VARIABLES DE ENTORNO
    • Vercel Dashboard → Settings → Environment Variables
    • Agregar:
      Name: VITE_API_URL
      Value: https://tu-backend.com/api
      Environments: Production, Preview

4️⃣  REDEPLOY (si ya deployó)
    • Vercel Dashboard → Deployments → Latest
    • Redeploy

✅ RESULTADO:
    • App disponible en: https://tu-proyecto.vercel.app
    • Auto-deployment en cada push a main
    • CDN global activo
    • Logs disponibles en Vercel Dashboard
